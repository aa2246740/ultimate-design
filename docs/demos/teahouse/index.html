门店

山泉旁的一间茶屋

不卖热闹。只煮山上的水，泡三道茶。

茶屋贴着南坡泉眼，清晨先舀一桶清泉，炭炉上温着。泉眼在雨后会涨，水声压过檐下风铃；晴天则细得像线，刚好盖住翻书的声响。

店里只设六席。席间不播乐，客人自带书也行，或对着窗外松影坐一会儿。茶从壶里出来，第一道看汤色，第二道才论香。

我们不为赶场。预约写清时段与人数，到点开门，坐满便止。

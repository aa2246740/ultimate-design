Agent Skill · v0.6.0 · MIT

把设计做出来,也把判断留下来。

Ultimate Design 是给 AI Agent 用的设计工作流:收到模糊需求时先理顺目标和内容,做完后对着真实渲染结果复查,最后把 DESIGN.md 契约留给下一位接手的人。

看它怎么工作

一次运行 · 五阶段

Request Anchor

写清这次要解决什么、谁来用、什么不能丢。后续细节不能盖住原始诉求。

Content contract

先排信息层级与必须准确的句子,再开版式。CONTENT.md 成为页面文案的唯一来源。

Direction

选定色彩、字体、密度与参考策略,并写进 DESIGN.md 的 taste dials。

Artifact

落到真实页面或材料,带上 data-ud-check 语义区,方便渲染审计对位。

Rendered review

对着真实渲染修问题,把未解决风险写清楚,再交给下一位接手的人。

知识库

模式与路线

默认直接做;要对齐时再对齐。

默认 (YOLO)

不盘问用户,从现有材料推断,先交出完整的第一版。

--pro

受众、信息重点、品牌气质、验收标准先对齐,再开始做。

Portable Specialist

多域高风险工作时,Integrator 分发工单,专家返回结果包,最终制品只有一个执笔人。

  • Build 做出来
  • Audit 只诊断
  • Redesign 保内容换结构
  • Study 提取可迁移机制

怎么开始

装进宿主,再说你要的结果。

npx ultimate-design-skill@latest --target codex
npx ultimate-design-skill@latest --target claude-code
npx ultimate-design-skill@latest --target pi-agent

普通模式

$ultimate-design 帮我把这份研究做成一个便于阅读的网页。先处理内容和设计方向,再实现、复查并修掉明显问题。

--pro 模式

$ultimate-design --pro
我要做一个面向投资人的产品官网。先和我确定受众、信息重点、品牌气质和验收标准,再开始实现。

交付时看什么

交出去的,不只有一个链接。

  • 需求和取舍写在 DESIGN.md。
  • 参考资料有来源和用途。
  • 页面、幻灯片或图形按实际尺寸检查过。
  • 未解决的风险被如实写下。
